PLM Patron : votre commerce dans votre poche

L’app gratuite du patron, offerte avec chaque logiciel PLM (sauf Comptabilité et École). Ventes, caisse, stock et alertes de vos établissements sur votre téléphone, en lecture seule, même quand vous êtes loin.

  • Téléphone Android

    Scannez le QR code ou touchez le bouton, puis ouvrez le fichier téléchargé. Si le téléphone le demande, autorisez l’installation depuis cette source.

    Télécharger l’app Android

  • iPhone (et tout autre téléphone)

    La version web sécurisée s’ouvre dans Safari. Touchez Partager puis « Sur l’écran d’accueil » : elle s’ouvre ensuite comme une app.

    Ouvrir la version web

Relier un établissement (une seule fois)

  1. Dans le logiciel PLM, sur le poste de l’établissement : Administration → Établissement → carte « PLM Patron » → « Relier un téléphone ». Un QR code et un code à 6 chiffres s’affichent (valables 10 minutes).
  2. Dans PLM Patron : « Ajouter un établissement », puis scannez le QR code ou tapez le code.
  3. Cochez ce que ce téléphone peut voir (ventes, caisse et écarts, stock, alertes ; personnel et salaires seulement si vous le voulez), puis validez.
  4. C’est fait : les chiffres arrivent tout seuls, quelques minutes après chaque vente. Plusieurs établissements ? Recommencez pour chacun : ils s’ajoutent dans la même app.

Mode d’emploi

Accueil

Vos établissements, le chiffre d’affaires du jour et l’état de chaque poste (relié, hors ligne depuis quand).

Un établissement

Chiffre d’affaires du jour avec espèces et Mobile Money, fond de caisse et tiroir, relèves de fin de service, tables pas encore encaissées, ventes par heure, ruptures de stock complètes.

Alertes

Écart de caisse, rupture d’un produit vendu aujourd’hui, poste resté hors ligne : une notification arrive sur le téléphone.

Rapports

Jour, semaine ou mois comparés à la période d’avant, à partager par WhatsApp ou en PDF.

Questions

Des réponses toutes prêtes : meilleur produit, heure la plus chargée, comparaison avec la semaine passée…

Réglages

Mode clair ou sombre, notifications, établissements reliés (vous pouvez en retirer un à tout moment).

Aide

Les chiffres ne bougent pas

Le poste de l’établissement doit avoir internet. Sans réseau, il garde les chiffres et les envoie dès son retour ; la carte « PLM Patron » du logiciel indique « Pas d’internet depuis… ».

Le code est refusé

Il n’est valable que 10 minutes : demandez-en un nouveau dans le logiciel. Après 5 codes faux, il faut attendre 15 minutes.

J’ai changé de téléphone

Installez l’app sur le nouveau téléphone et reliez à nouveau chaque établissement avec un nouveau code.

L’app est-elle payante ?

Non. PLM Patron est gratuite pour les clients PLM, sans abonnement.

Le logiciel n’envoie que des résumés signés, jamais la base de données, les mots de passe ni les numéros des clients. Le téléphone ne peut rien modifier dans le logiciel.

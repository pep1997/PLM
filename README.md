# PLM — site vitrine

Site de **PLM, logiciels de gestion** — <https://plmgestion.com/>

Neuf logiciels de gestion pour les commerces et institutions d’Afrique de
l’Ouest : PLM Restaurant, PLM Maquis, PLM Hôtel, PLM Dépôt, PLM Commerce,
PLM Stock, PLM Clinique, PLM École, PLM Comptabilité. Installés chez le
client, sans internet, sans abonnement, en français, comptabilité SYSCOHADA.

## Ce dépôt ne contient que le site construit

La page, les feuilles de style, le script, les images et vidéos optimisées :
rien d’autre. Les sources (fabrique, configuration des applications, captures
d’origine en 4500 px, vidéos 4K) sont ailleurs — GitHub Pages, sur un compte
gratuit, ne publie que depuis un dépôt public.

Version 3 (01/10/2026) : fond orange au motif Nkonsonkonson, emblème PLM en
3D, vitrine des applications en un seul cadre interactif.
